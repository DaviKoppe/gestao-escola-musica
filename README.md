# Sistema de Gestão para Escola de Música

Sistema web desenvolvido para auxiliar na gestão de uma escola de música, a partir de necessidades reais identificadas durante o levantamento de requisitos.

A aplicação centraliza informações de alunos e mensalidades e oferece recursos para organização e acompanhamento da rotina administrativa da escola.

## 🛠️ Tecnologias

- Python
- Django
- Django REST Framework
- React
- JavaScript
- PostgreSQL
- Git/GitHub

## ✨ Funcionalidades

- Cadastro, edição e exclusão de alunos
- Gerenciamento de mensalidades
- Controle de status e vencimentos
- Gestão de informações administrativas
- Comunicação entre frontend e API REST

## 🏗️ Arquitetura

O projeto utiliza uma arquitetura separando frontend e backend:

- **Frontend:** React
- **Backend:** Django + Django REST Framework
- **Banco de dados:** PostgreSQL
